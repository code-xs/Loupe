# Contract Checklist 模板

```markdown
## Contract Checklist — {Issue-ID}

### 元信息
- **关联 Issue**: {issue_id}
- **关联 Fix Design**: {fix_design_ref}
- **溯源时间**: {timestamp}

### 溯源记录

| # | 溯源项 | 源文件 | 期望值 | 实际值 | 匹配状态 |
|---|--------|--------|--------|--------|----------|
| 1 | {API/资源/配置键名称} | {文件路径:行号} | {fix-design 中预期使用的值} | {从源文件实际检索到的值} | ✅/❌+修正动作 |

### 校验规则
- 涉及 N 个跨模块 API 调用/资源引用 → checklist ≥ N 条
- 源文件字段必须是可验证的文件路径+行号
- 期望值和实际值必须是具体字符串/签名，不允许模糊描述

### 校验结论
- **总溯源项数**: [N]
- **匹配项数**: [M]
- **不匹配项数**: [K]
- **校验结果**: [全部通过 / 存在不匹配（已修正）/ 存在不匹配（未解决）]
```
