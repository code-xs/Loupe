# ADR-005: PR 层级标签（🟢 / 🟡 / 🔴）

> **状态**：active
> **关联决定**：D5（v1.0 review 拍板）
> **关联 PR**：v4.1 PR-1 起所有 PR 必备（已合入）

## 1. 背景

不同 PR 的运行时风险差异巨大（纯文档 vs 编排器变更 vs wrapper 契约调整）。reviewer 阅读体感不一致 → 评审深度不匹配实际风险。

## 2. 决定

每个 PR 必须在元信息表的"层级"行用 emoji 标注风险等级：
- 🟢 **文档 / 注释 / CI 守门**：reviewer 关注语义一致性 + 链接可达性
- 🟡 **协议 / DSL 元素文本变更 / legacy 兼容触达**：reviewer 关注 LLM 推理路径稳定性 + 老会话回放
- 🔴 **运行时分支 / wrapper 输入契约 / phase 出口宏标签**：reviewer 关注跨平台回归矩阵 + DoD 完整性

## 3. 替代方案

- **方案 X**（不分级，统一深度评审）：被拒绝。理由：① 评审成本过高；② 文档 PR 被过度评审会拖慢主路径；③ 无法在 PR description 一眼标定关注重点。

## 4. 影响

- **PR 模板**：所有 v4.x 后续 PR 元信息表新增"层级"列
- **跨平台 DoD**：🔴 PR 强制跨平台全量回归；🟡 PR 抽样回归；🟢 PR 仅 Cursor / Trae 主路径回归
- **回滚等级**：🔴 → 高；🟡 → 中或低；🟢 → 极低
