# 环境因子阈值参考

> 本文件为功能疑难专项子工作流 F1（环境与上下文重构）提供环境因子异常阈值基准。
> 阈值为参考值，实际判断需结合具体设备、OS 版本和应用场景。

## 内存与进程管理

| 因子 | 正常范围 | 警告阈值 | 危险阈值 | 平台差异 |
|------|---------|---------|---------|---------|
| 可用内存 (Available RAM) | > 500MB | 200-500MB | < 200MB | iOS 无公开 API，需通过 os_proc_available_memory 间接获取 |
| LMK 事件 (Low Memory Killer) | 无 LMK 事件 | 30s 内 1 次 | 30s 内 >= 2 次 | Android 特有；iOS 对应 Jetsam |
| 应用内存占用 | < 设备 RAM 15% | 15%-25% | > 25% 或触发 didReceiveMemoryWarning | iOS 阈值因设备而异 |
| OOM 风险 | 正常 | 接近 Jetsam 限额 80% | 接近 Jetsam 限额 95% | iOS Jetsam 限额按设备型号不同 |

## 温控与功耗

| 因子 | 正常范围 | 警告阈值 | 危险阈值 | 影响行为 |
|------|---------|---------|---------|---------|
| CPU 温度 | < 40°C | 40-50°C | > 50°C | 系统可能触发降频 |
| Thermal State (iOS) | .nominal | .fair | .serious / .critical | .serious 时 CPU 降频 50%+ |
| 电池温度 | < 35°C | 35-42°C | > 42°C | 系统可能限制后台活动 |
| CPU 使用率（应用） | < 50% | 50-80% | > 80% 持续 > 5s | 可能触发 watchdog 或 ANR |

## 网络状态

| 因子 | 正常范围 | 警告阈值 | 危险阈值 | 诊断方式 |
|------|---------|---------|---------|---------|
| RTT (Round-Trip Time) | < 100ms | 100-500ms | > 500ms | ping / 应用内埋点 |
| 丢包率 | < 1% | 1-5% | > 5% | 连续 3 次请求超时 |
| 网络切换 | 无 | WiFi↔蜂窝切换 | 切换后 IP 变更导致连接中断 | NetworkCallback / NWPathMonitor |
| DNS 解析耗时 | < 50ms | 50-200ms | > 200ms 或失败 | — |

## 磁盘 I/O

| 因子 | 正常范围 | 警告阈值 | 危险阈值 | 影响行为 |
|------|---------|---------|---------|---------|
| 可用存储空间 | > 1GB | 500MB-1GB | < 500MB | 可能导致写入失败 |
| 数据库锁等待 | < 10ms | 10-100ms | > 100ms | SQLite BUSY / Room 锁竞争 |
| SharedPreferences 写入延迟 | < 5ms | 5-50ms | > 50ms (主线程) | Android apply() vs commit() |

## 生命周期与系统干预

| 因子 | 关注场景 | 判断标准 | 关联风险 |
|------|---------|---------|---------|
| 前后台切换 | 异常前 10s 内 | 频率 > 2 次/10s | 订阅丢失、任务取消、状态重置 |
| 权限撤销 | 运行时权限被收回 | 异常窗口内检测到 onRequestPermissionsResult 否定 | 功能降级未被正确处理 |
| 配置变更 | Configuration Change 触发 Activity 重建 | 语言/字号/暗色模式/屏幕旋转 | 状态丢失、Fragment 叠加 |
| 进程回收与恢复 | 后台进程被杀后恢复 | savedInstanceState != null | 恢复路径未正确处理 |
| 系统弹窗干预 | 系统级 Alert 中断应用 | 电话/低电量/系统更新提示 | onPause 时序打断业务流 |
| Doze / App Standby | Android 后台限制 | 网络请求被延迟、JobScheduler 被推迟 | 定时任务、推送处理受影响 |

## 使用指南

1. **对照检查**：F1 阶段逐一对照上述因子，记录观察值与阈值的偏离程度
2. **关联评级**：
   - 因子值在"危险阈值"范围 + 时间窗口匹配 → 关联等级 A
   - 因子值在"警告阈值"范围 + 时间窗口匹配 → 关联等级 B
   - 因子值在"正常范围"但有弱关联线索 → 关联等级 C
3. **缺失处理**：无法获取的因子必须标记 `[Unavailable]`，不得使用默认值填充
