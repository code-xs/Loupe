# Functionality Deep-Dive Agents

当前目录包含 Functionality Deep-Dive 子工作流的专项角色定义：

- `context-reconstructor.md`: 环境与上下文重构专家
- `state-analyst.md`: 状态机与数据流分析专家
- `temporal-analyst.md`: 时序与竞态分析专家
- `challenger.md`: 功能疑难专项质疑员
- `arbiter.md`: 功能疑难专项仲裁员
- `defensive-fix-architect.md`: 防御性修复设计专家

首批执行可优先使用前 5 个角色，`defensive-fix-architect.md` 可在 Stage 5 启用。
